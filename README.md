# Eswar Portfolio

A responsive personal portfolio built with React, TypeScript, Vite and Motion.

## Requirements

- Node.js compatible with the Vite version in `package.json`
- npm

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

1. Add your approved resume PDF as `public/resume.pdf` for the Hero resume link to work.
2. Review all professional case-study wording against your employer's confidentiality policies.
3. Add your GitHub URL when you are ready to publish it.
4. Verify contact details and social links.

## Project structure

```text
src/
  components/   Shared UI and animation components
  sections/     Portfolio page sections
  assets/       Static assets
  App.tsx       Page composition
  App.css       Section and component styling
  index.css     Global design tokens and base styles
```

Professional work is described as high-level, anonymized case studies. No internal source code, customer data, screenshots or private repository links are included.
